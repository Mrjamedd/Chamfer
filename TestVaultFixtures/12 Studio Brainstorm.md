# Studio name brainstorm

Words I like: field, hinge, common, north, quiet, relay, little, workshop.

Possible directions:

- Common Field — sounds open but maybe like a landscaping company
- North Relay — energetic, slightly technical
- Quiet Workshop — accurate but perhaps too precious
- Hinge Studio — simple, though there are probably many already

The name should work for software and writing projects. It should not sound like a giant agency with fifty employees when its currently two people. Avoid creative spelling that has to be explained every time.

Ask Lena what she hears in “Common Field”. I like it but cant tell whether it feels collaborative or vague.
